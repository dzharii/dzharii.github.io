Software 2025

This document compiles software‐related links extracted and categorized from markdown posts processed between July 2021 and May 2025. It covers command-line utilities, desktop applications, web services, browser extensions and more, providing a concise, curated catalog of tools for quick reference.

[[TOC]]

🖥️⚙️ Command-Line Applications​

📚 Documentation Tools​

  • tldr pages – Community-maintained, concise cheat-sheets for over 200 Unix commands, providing brief examples and options to speed up your shell workflow without consulting lengthy man pages.
  • Vale – Command-line style checker ensuring consistent documentation.

🧩💻 Desktop Applications​

🔍📐 Code Navigation & Analysis​

  • Sourcetrail – Cross-platform interactive source-code explorer that indexes your C/C++, Java, Python and other projects to visualize call graphs and class hierarchies, helping you navigate and understand unfamiliar codebases without manual grep searches.
  • include-what-you-use – Static analysis tool for C/C++ that suggests minimal header inclusions.

🔄📂 File Sync & Backup​

  • Syncthing – Open source peer-to-peer file synchronization tool keeping folders identical across devices.

🗓️📈 Productivity & Task Management​

  • Homechart – Self-hosted organizer for household chores, finances and inventory.
  • Sorted³ – Scheduling to-do list app that auto-generates daily plans.
  • Org mode – Plain-text productivity system for Emacs with outlines and agenda.
  • Plan – Aggregates calendars and tasks from multiple services into one dashboard.
  • ScriptKit – Open-source toolkit to launch scripts and automate developer workflows.
  • AppFlowy – Open-source workspace alternative to Notion with local data storage.
  • espanso – Cross-platform text expander that replaces typed keywords with snippets.
  • Heynote – Developer-focused scratchpad for quick notes with optional GitHub repo at heyman/heynote.
  • Nullboard – Minimalist self-hosted Kanban board that's compact and keyboard-driven.

🔧🔌 API Clients​

  • Yaak – Fast, offline-first, Git-friendly API client for REST, GraphQL, WebSocket, SSE and gRPC endpoints. Store requests as plain-text files for version control, encrypt secrets locally, and replay or share them from a desktop GUI.
  • REST Client – Send HTTP requests directly from VS Code and inspect responses without leaving the editor.

🖼️📊 Diagramming & Drawing​

  • drawio-desktop – Electron-based diagrams.net app that works offline for creating flowcharts and architecture sketches.
  • d2 – Diagram scripting language that turns text files into professional diagrams.
  • Wireflow – Browser-based user flow tool for prototyping interfaces without design software.
  • Graphviz – Classic open-source graph visualization suite for rendering structured diagrams from DOT files.

🗄️📂 File Managers​

  • eza – Modern replacement for ls with colors, git status and icons.

🖥️💻 Virtualization​

  • Docker-OSX – Run macOS in a Docker container using KVM for near-native performance.
  • far2l – Modernized port of the classic FAR Manager with terminal and GUI interfaces for Linux and macOS.
  • quickemu – Quickly spin up optimized Windows, macOS or Linux VMs with simple config files.

💾 Legacy Software Ports​

  • 123elf – Native Linux port of Lotus 1-2-3 spreadsheet classic.

📝 Markdown Editors​

  • MarkText – Cross-platform Markdown editor with live preview and minimal UI, built on Electron.
  • Markably – Web-based Markdown editor with live preview and distraction-free mode.
  • Zettlr – Cross-platform Markdown editor geared toward academic writing.
  • ghostwriter – Minimalist Markdown editor with focus mode and live preview.
  • Zim – Desktop wiki that stores notes in plain text files with wiki-style links.
  • Obsidian – Markdown knowledge base app with local graph view and extensive plugins.
  • Logseq – Open-source outliner for managing notes and tasks in plain text.
  • Dendron – Hierarchical note-taking extension for VS Code.
  • TiddlyRoam – Self-contained wiki notebook inspired by Roam Research.

🎛️ Audio Tools​

  • Soundux – Cross-platform soundboard routing audio to specific applications.

🌐📡 Networking Utilities​

  • wgcf – Unofficial CLI for Cloudflare Warp that generates WireGuard profiles. wgcf register && wgcf generate produces a config ready for wg-quick.
  • bombardier – Fast HTTP(S) benchmarking tool written in Go for stress testing APIs and websites.
  • dasel – Query and update JSON, YAML, TOML, XML and CSV data from the command line using a simple selector syntax.
  • wttr.in – Curl-friendly weather forecast service; run curl wttr.in for an instant report.
  • Matterbridge – Bridges messages between Slack, Discord, Matrix and other chat platforms via a single binary.
  • sharing – Simple CLI to share files or directories over HTTP for quick transfer to mobile devices.

🛡️ Security Tools​

  • Snort – Open-source network intrusion detection and prevention system.

🗃️ Data Processing Tools​

  • Miller – Command-line Swiss army knife for CSV, TSV and JSON data manipulation.
  • fastgron – High-performance JSON to GRON converter built with simdjson.
  • fq – Binary data processor combining jq, hexdump and dd functionality.

📊 Data Visualization​

  • Perspective – Interactive analytics component optimized for large or streaming datasets. Create dashboards and notebooks in the browser or Python.

🗜️ Compression Tools​

📈🔬 Profiling & Benchmarking​

  • PerfView – Windows performance analysis tool with CPU and memory profiling.
  • Speedscope – Interactive flamegraph viewer for performance profiles.
  • pigz – Parallel implementation of gzip that utilizes multiple CPU cores for faster compression.
  • nvtop – Terminal-based monitor displaying GPU utilization and processes across vendors.

☁️🛠️ Web Services & Self-Hosted Platforms​

🚀🔄 Platform-as-a-Service & App Deployment​

  • Coolify – Open-source PaaS you can install on your own server under a minute. Provides one-click deployments for Docker-based applications, automated SSL, database provisioning, and built-in CI/CD pipelines as a free Heroku/Netlify/Vercel alternative.
  • PocketBase – Open source backend in a single Go binary providing realtime database, auth and file storage.

🌐📄 Static Site Hosting​

  • GitHub Pages – Build and host static websites straight from your GitHub repository.

🪟🤖 OS Automation Tools​

  • Generate autounattend.xml files for Windows 10/11 – Web service that guides you through selecting Windows Setup settings (partitions, locale, user accounts, drivers) and outputs a complete autounattend.xml file to automate clean installations on Windows 10/11.

  • LibreAutomate – Windows automation tool and C# scripting environment.

🧾🔄 File Conversion & Processing​

  • html2text – Convert HTML into Markdown-formatted text from the command line.
  • Rembg – Command-line tool to remove image backgrounds using machine learning.
  • UpScayl – Free AI-powered image upscaler for Windows, macOS and Linux.
  • BackgroundRemover – Python CLI to strip backgrounds from photos and videos.

🎞️ Video Editing​

  • LosslessCut – Simple cross-platform tool for quick, lossless trimming of video and audio files.
  • VERT.sh – Privacy-focused, open-source web app for converting images, audio, video and documents. All non-video conversions run client-side (no upload), while videos use fast servers; no ads or size limits.
  • Squoosh – Progressive web app that compresses images locally in the browser using modern codecs.

📰 RSS & Feed Readers​

  • FreshRSS – Lightweight self-hosted aggregator for RSS and Atom feeds.
  • TT-RSS – Web-based news feed aggregator you can self-host.
  • Fluent Reader – Modern cross-platform RSS reader for desktops.
  • Stringer – Self-hosted, anti-social RSS reader built on Ruby on Rails.
  • CommaFeed – Google Reader inspired self-hosted feed reader with multiple layouts.
  • Nextcloud News – RSS/Atom aggregator app for Nextcloud.
  • Yarr – Self-hosted RSS reader with web and terminal interfaces.
  • selfoss – Multipurpose PHP feed reader and aggregator.
  • wReader – Minimal Chrome app for reading web feeds offline.
  • Liferea – GTK-based desktop feed reader for Linux.
  • RSS-Bridge – Generates RSS feeds for sites lacking them.

🏠🔌 Home Automation​

  • Gladys Assistant – Privacy-first open-source home assistant for controlling smart devices.

  • Frigate – Local NVR for Home Assistant with real-time object detection using TensorFlow and OpenCV.

💻📂 Git Hosting​

  • soft-serve – Minimal Git server you operate from the command line, offering a simple TUI for browsing repositories.
  • Gitea – Lightweight community-managed alternative to GitHub for running your own code hosting platform.
  • gogs – Compact Go-based Git service that runs on low-resource servers with a familiar web interface.

🔗🛠️ Developer Tools​

  • curlconverter – Converts curl commands into code snippets for languages like Python, JavaScript and Go.
  • BookStack – Self-hosted wiki and knowledge base platform for organising documentation.
  • rss-proxy – Generate RSS or Atom feeds for almost any website by analyzing its static HTML structure.
  • jsoncrack.com – Visualize JSON structures as interactive graphs right in the browser.
  • Erlog – Minimalist log collector for forwarding structured logs to a central service.
  • changedetection.io – Monitors websites for content changes and sends notifications.
  • oidc-debugger – Web tool for testing OAuth and OpenID Connect flows.
  • IdentityServer – Flexible OpenID Connect and OAuth framework for ASP.NET Core.
  • toapi-search – Build custom search APIs with the Toapi web scraping framework.
  • CloudQuery – Turns websites into APIs via visual scraping rules.
  • quicktype – Generate type-safe code from JSON instantly in multiple languages.
  • gamecontroller.js – JavaScript library for handling gamepad input in web apps.
  • PSReadLine – Enhanced command line editing experience for PowerShell.
  • FTXUI – C++ library for building modern terminal user interfaces with widgets.
  • RapidCheck – Property-based testing framework for C++ inspired by QuickCheck.
  • lazygit – Terminal UI for Git commands with interactive staging and history browsing.

🏛️📊 Transparency & Monitoring​

  • Capitol Trades – Free platform tracking U.S. Congress stock transactions. Browse and filter members’ buy/sell history by party, committee or issuer, and view aggregated charts of recent trading volume to spot potential conflicts of interest.

🧠🖼️ AI Tools​

  • slidehero.ai – AI-powered slide generator: paste your outline or bullet points and instantly produce formatted PowerPoint or Google Slides decks with layouts and graphics tailored to your content.
  • imaginAIry – Python tool for generating images with Stable Diffusion from the command line.
  • Riffusion – Creates music by running Stable Diffusion on spectrograms; open source at riffusion/riffusion.
  • PrivateGPT – Run GPT-based question answering locally on your documents with no Internet required.
  • LM Studio – Desktop hub for downloading, running and managing local large language models.
  • Onyx – Open-source Gen‑AI chat platform that indexes your team's private knowledge.
  • Chain of Recursive Thoughts – Toolkit that iteratively refines LLM answers by generating alternatives and choosing the best.

🌐🧩 Browser Extensions & Tools​

📤🔗 File Sharing​

  • filepizza – Zero-setup peer-to-peer file sharing in the browser. Drag a file into the page, get a one-time URL, and let recipients download directly via WebRTC—no servers or storage required.

🗂️📥 Archiving & Offline Access​

  • Omnom – Browser extension and service that saves fully self-contained HTML snapshots of web pages for offline reading and archiving. Captures images, styles and scripts so pages remain accessible even if the original site changes.

🧘📅 Productivity Enhancers​

  • Lofi Tab – New-tab extension showing customizable widgets: a to-do list, clock, weather forecast and rotating lofi-style background music for focused browsing sessions.
  • clockish.co.uk – Displays the current time in human-friendly phrases (e.g. “quarter past three”) instead of numbers. Embed as a widget or visit the site for a playful alternative to digital clocks.

📚🗣️ Educational Tools​

  • Fluentsubs – Web app offering daily language exercises using real-world video subtitles. Watch a short clip and fill in blanks to practice comprehension and vocabulary in context.

🧪🔍 Interactive Explorers​

🧱 3D Modeling Tools​

  • DSLCad – Lightweight language and interpreter for building 3D models.

  • Sweet Home 3D – Free interior design application for drawing house plans and arranging furniture in 3D.

🗃️🔎 Database Tools​

  • SQLite File Format Viewer – Web-based tool for inspecting SQLite database internals. Upload a .sqlite file or use a demo DB to explore page structures, B-tree layouts, freelist pages and WAL entries via clickable diagrams.
  • chartdb – Database diagramming tool that creates entity-relationship charts from SQL queries.

🗺️ Map Tools​

  • Overpass Turbo – Web-based interface for crafting and running Overpass API queries on OpenStreetMap data.
  • flatdraw – Simple React canvas app for quick drawings with a responsive UI.

📟🔌 Device & Embedded Projects​

🍓📡 Raspberry Pi Projects​

  • Subway E-Ink Tracker – Raspberry Pi and e-ink display project that fetches live train schedules and weather data to render a low-power, wall-mounted information panel. Includes code to drive Waveshare e-ink screens and parse public transit APIs.

📷🔧 Camera Utilities​

  • webcamize – CLI tool letting you use DSLRs, mirrorless cameras, camcorders or smartphones as Linux webcams. Configures UVC drivers and handles firmware quirks so professional cameras appear as /dev/video* devices.
  • matrix-webcam – Adds Matrix-style green code rain effect to your webcam feed for video calls.

📱 Mobile Utilities​

  • scrcpy – Mirror and control Android devices from your computer via USB or Wi-Fi.
  • display-switch – Switch monitor inputs automatically when a USB device connects.

🧠🧰 Development Environments​

🧩🧵 Moldable IDEs​

  • Glamorous Toolkit – Interactive, moldable IDE built on Pharo Smalltalk and JavaScript runtimes. Offers real-time object inspectors, context-aware micro-tools and live code modification to explore and evolve applications without stopping execution.

🛠️ Programming Languages & Compilers​

  • SectorC – 512-byte x86 boot sector C compiler written in assembly.
  • mold – High-performance linker drop-in compatible with GNU ld and gold.
  • ccache – Compiler cache that speeds up recompilation by caching previous build outputs.

🗄️🛢️ Database Engines​

  • DuckDB – In-process analytical SQL database optimized for fast local queries without a server.
  • cr-sqlite – SQLite extension adding CRDT-based multi-master replication for offline-friendly apps.

🎮 Games & Emulators​

  • webrcade – Feed-driven retro gaming platform that runs classic games in the browser.
  • Genesis-Plus-GX – Accurate and portable Sega 8/16‑bit emulator.
  • QuickParty.Games – Collection of instant multiplayer browser party games.
  • The Password Game – Puzzle where evolving password rules lead to absurd challenges.
  • DuckStation – High-accuracy PlayStation emulator for Windows, Linux and macOS.
  • DoomPDF – Doom source port that runs entirely inside a PDF file.
